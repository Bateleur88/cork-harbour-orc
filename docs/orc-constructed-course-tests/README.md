Test documents in Sail Scoring's ORC constructed course format, made from the 27 September 2026 Race 1 course. Both were pasted into Sail Scoring's Add start dialog on 10 October 2026 and accepted. 27-sept-race1-complete.json is the full course (six legs, 4.54 nm). 27-sept-race1-start-line-missing.json is the same course with the start line not recorded: the first leg is left out and a warning is put at the front of the name. In that test, Sail Scoring used the warning as the race title, so the name is not the right place for warnings; this is an open question for Mark. These files are the target output for the Course Plot page's "Copy for Sail Scoring" button.
