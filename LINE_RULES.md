# Start and finish line rules (agreed 26 Oct 2026)

1. RCYC start and finish lines.
   - Grassy Walk: a known permanent line from a point ashore to a fixed navigation mark. Grassy Mid is its measured, known midpoint. Used as a start it is "Grassy Start", as a finish "Grassy Finish". Nothing needs recording on the day.
   - Dosco and No.8 starts: typically the mark itself is one end of the line and the committee boat the other. Occasionally the committee boat anchors and lays a pin in the vicinity of Dosco or No.8 instead; then the line is committee boat to that laid pin.
   - DBSC has the same type: "The Hut" plus a laid buoy or RIB.
2. Dosco and No.8 finishes: a line from the committee boat to the mark. Boats never finish at the mark itself: a committee boat must be there to record finish times. The committee boat may lay a pin near the mark instead.
3. Laid lines: a committee boat at one end and a Start Pin at the other, both laid on the day. The committee boat is usually at the starboard end, but that is not a rule. The committee boat position is normally recorded.
4. Placing pins:
   - A pin placed by distance and bearing is measured from the committee boat only.
   - A pin is never placed by distance and bearing from any other mark, harbour or laid.
   - When a harbour mark is used as a line end, the mark itself becomes the pin end. No pin is laid at the mark (no separate pin record).
   - The committee boat can be placed by distance and bearing from a harbour mark.
5. Finish sequence: the first option is to finish on the start line. Next, the committee boat stays and a new Finish Pin is laid from it. Failing that, the committee boat moves and a new line is laid. Earlier races' Finish Pins are unlikely choices.
6. Finishing on the start line: it is standard procedure, so it is the first option in the finish list, but the page never applies it by itself. Until the RO chooses a finish, the finish line shows "Line not set".
7. One end missing: using the known end as the midpoint estimate is the RO's tap, never automatic.
8. Never silently resolve anything by autofill or guessing. Never invent a leg; flag what is missing.
9. Colours: red for critical (a missing line), orange for non-critical.
10. RIBs do not ping existing marks.
11. No auto-picking and no defaults for line ends. Every start and finish line end is the RO's choice from a list that starts empty.
12. Nothing carries forward between starts. A pin from an earlier start is never applied to a later one; it stays available as a choice.
13. Setting a start line. The list starts empty. Either:
   - Use existing line: Grassy Start (always available), plus lines already set up that day, named "Race N · Start N · start line" or "Race N · Start N · finish line". Choosing one sets both ends exactly as that line was set up.
   - Create a line manually:
     - Committee boat: a recorded or typed position, or placed by distance and bearing from a harbour mark.
     - Other end: a recorded or typed pin, a harbour mark (the mark itself is the end), or a pin placed by distance and bearing from the committee boat.
14. Setting the finish line. The list starts empty. In order:
   - Use start line as finish line (this start's start line);
   - Grassy Finish (always available), and existing finish lines as available (e.g. "Race 1 · Start 1 · finish line");
   - Create a finish line manually, by the same method as a start line.
15. What is available in the manual lists:
   - Pins: pins recorded by a RIB, and typed pin positions.
   - Committee boat: committee boat positions recorded, each with its recorded time, and typed committee boat positions.
   - Harbour marks: chosen from the harbour marks.
16. Course marks are outside these rules. Laid course marks (Windward, Leeward and so on) keep using the latest RIB fix as now.
17. Course marks from earlier races stay reusable, labelled with their race and time (e.g. "(R1 10:40)").
18. Card courses: importing a card course with a Dosco, No.8 or Grassy start or finish does not set the line. The RO must still set the start line and the finish line by rules 13 and 14.
19. Existing lines follow corrections: a start using "Race N · Start N · start line" (or finish line) follows any later correction to that line.
20. Mark as midpoint estimate: using Dosco or No.8 as the finish (or start) line midpoint stays available only as an estimate under rule 7, clearly marked as one. The RO must still confirm the lines.
21. Start Pin as a finish line end: a Start Pin can be chosen as an end of a finish line.
22. Time on the water: each placing box starts with the start time, and the RO can edit it.
23. Wind is outside these rules: each start takes the day's wind until it is sent or the start time passes, as now.

Saved races up to now are left as they are. Their saved line ends must keep reading the same (e.g. 18 Oct Race 1 Start 1 stays at 1.48 nm).

## Clarifications (agreed 26 Oct 2026)

C1. Lines are named in full: "Race 1 · Start 1 · start line", "Race 1 · Start 1 · finish line".
C2. The finish list offers, after "Use start line as finish line" and Grassy Finish, the start lines and finish lines of earlier starts.
C3. "Lines already set up that day" means lines of earlier starts only (earlier in the same race, or in earlier races).
C4. If a line that a start is using is later cleared or left with one end, the start using it shows "Line not set".
C5. A Dosco or No.8 start before the committee boat is known: the RO chooses Dosco (or No.8) as the other end; one end is then missing, and "Use Dosco as the line's midpoint (estimate)" is offered as the RO's tap under rule 7.
C6. Placing the committee boat from a harbour mark does not make that mark the other end. The RO chooses the other end separately.
C7. A Finish Pin can be chosen as a start line end, as a Start Pin can be chosen as a finish line end (rule 21).
C8. "Finish boat" fixes appear in the committee boat lists, with their type, race and time.
C9. The time on the water in a placing box does not follow a later change of start time.
C10. A start saved before the rework keeps its saved ends as the RO's choices when it is edited; its lists do not reset.
C11. Rolling back to .45b after new records are saved is accepted as it is: .45b may misread starts saved under the new rules.
C12. Rule 10 is a fact about recording; the course page needs no change for it.
C13. Copy for Sail Scoring keeps its current estimate wording (e.g. "Dosco used as midpoint").
C14. A line with one end chosen and no midpoint tapped shows the red "Line not set".
C15. With the finish "Line not set", Copy for Sail Scoring says INCOMPLETE and WhatsApp Send is not held back, as now.
C16. When a start saved before the line rules is first changed, it keeps as the RO's choices only what it saved as its own: an end chosen in its lists, a pin set or an end placed, a midpoint, a Grassy start or a Card mark the RO tapped, and a finish line the RO chose (shared from another start, Laid line's own finish, a Finish Pin as the midpoint). Not kept: an Auto pick, live or saved with the course, with no pin set or end placed behind it (a "Use it" tap on a newer fix among them, as the saved data cannot tell it apart); a pick carried from the start before; a card course's own start or finish on Automatic, its Grassy start among them; and a saved finish "Same as the start line", unless the start's record also has a finish line or a Card mark tap saved. A line not kept shows "Line not set".
